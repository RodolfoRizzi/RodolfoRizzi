# Rodolfo Rizzi

**AI Consultant & Data Scientist.**

Figuring out where AI can help, and checking whether it did.

### Public projects


- **[MyMentorLLM](https://github.com/RodolfoRizzi/MyMentorLLM)**: multi-agent LLM simulation and evaluation at scale, across frontier text, audio-text and speech-to-speech models, released as a public [🤗 dataset](https://huggingface.co/datasets/RodolfoRizzi/MyMentorLLM-dataset) and [paper](https://arxiv.org/abs/2607.25667). [Explore the project website](https://mymentorllm.web.app)
- **[ai-app-cognitive-rehabilitation](https://github.com/RodolfoRizzi/ai-app-cognitive-rehabilitation)**: an AI app for personalized rehabilitation of aphasia and Alzheimer's patients, built with clinicians.
- **[MHDS-pooling-system](https://github.com/RodolfoRizzi/MHDS-pooling-system)**: a dashboard to filter and export a large LLM-generated persona dataset.
- **[realtime-voice-agent-platform](https://github.com/RodolfoRizzi/realtime-voice-agent-platform)**: an AI app for professional training, with real-time voice and automated session scoring.
- **[hpc-preprocessing-qc-ml-pipeline](https://github.com/RodolfoRizzi/hpc-preprocessing-qc-ml-pipeline)**: a data preprocessing and analysis pipeline turning terabytes of raw files into data ready for deep-learning models on an HPC cluster.
- **[ai-livability-app-from-open-data](https://github.com/RodolfoRizzi/ai-livability-app-from-open-data)**: 390,000 public data points on services, transport and environment, turned into an app that shows local government where to invest.
